Worked example · Graphing

Graph the function that exists—not imaginary points.

For y = √(x − 10), the real graph begins at x = 10. SepCalc keeps the domain, trace point, derivative, root, and numerical limits together instead of drawing through undefined values.

Real domainx ≥ 10
Root(10, 0)
Trace at x = 14y = 2
Derivative at x = 14dy/dx = 0.25

1. Keep the domain visible

The real-valued expression is defined only when x − 10 ≥ 0. Values below 10 are excluded rather than treated as failed evidence against the graph.

2. Trace a point deterministically

At x = 14, substitution gives √4 = 2. The trace keeps the selected x, resulting y, and local derivative together.

3. Preserve the analysis

Version 1.0.2 keeps graph traces, value tables, roots, extrema, derivatives, and integrals available while you continue working.

4. State the numerical limits

Sampled plots and numerical analysis depend on the visible domain and reported tolerance. The derivative is not finite at the endpoint x = 10.
